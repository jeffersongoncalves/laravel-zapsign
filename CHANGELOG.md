# Changelog

All notable changes to this project will be documented in this file.

## 1.0.0 - 2026-10-22

First release: ZapSign REST client (documents, templates, signers, batch signing), client-side rate limiting (500 req/min) with Retry-After aware retries, database persistence (documents, signers, webhook calls), queued jobs (CreateDocument, SyncDocument, ProcessWebhookCall, StoreSignedFile) and header-secured webhooks.
